    How this model was made

    RDKit built the 3D structure and minimised it with the MMFF94 force field, keeping every stereo mark in the SMILES (where RDKit drops a mark, the mirror image that matches it is used). Atoms are named by element and their position in the SMILES. Priorities use the first CIP rule only (atomic numbers, sphere by sphere), so check centres that need later rules. The R or S above is read from the model as it appears on screen.
